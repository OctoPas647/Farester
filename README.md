# Farester

A book reader that reads your books aloud at adjustable speed (up to 4x) to help you read faster.

- Library with stats (time per book, reading speed)
- Read-aloud with multiple voices and speed control
- Tap a hard word for an explanation
- Imports popular book formats (PDF, EPUB and more)

## Run it

Open `index.html` in a browser. It's a single self-contained file, so it also works offline once loaded.
